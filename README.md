## 🌐 Deployment

### GitHub Pages (Free)
```bash
git init
git add .
git commit -m "Initial commit: Moe Kyaw Aung Portfolio v2.0"
git branch -M main
git remote add origin https://github.com/Dev-moe-kyawaung/moe-kyaw-aung-portfolio.git
git push -u origin main
```
Then: Settings → Pages → Select branch `main` → Save

### GitLab Pages (Free)
```bash
git remote add gitlab https://gitlab.com/Dev-moe-kyawaung/moe-kyaw-aung-portfolio.git
git push -u gitlab main
```
